mikduck vs MikhMon

Alur hotspot familiar — stack & pengalaman beda total. Tabel fitur operasional:

Fitur mikduck MikhMon
Cara jalan Desktop installer (Electron) — tanpa PHP Web + Apache/Nginx + PHP
Generate & print voucher Ya · Quick Print · template · riwayat Ya · klasik & matang
Profile hotspot Ya · Expired / Record / lock MAC Ya
User online / kick Ya · WebSocket live Ya · refresh / polling
MAC binding Binding / Unbinding di UI Ya
Finance / report jual Manual + sync script Mikhmon Ya (pola komunitas)
Hak akses operator Role granular di API Admin-style klasik
Tema & bahasa Light / Dark / System · ID & EN UI web klasik
DHCP / queue / tools Ya (terintegrasi di app) Tergantung setup / plugin
Stack Electron · React · FastAPI · SQLite PHP · browser

mikduck menghormati MikhMon sebagai referensi alur hotspot — bukan pengganti wajib.
