Mulai dalam 3 langkah

Tidak perlu USBWebserver, XAMPP, atau Docker hanya untuk jalanin aplikasi.

Install

Jalankan Setup di Windows, atau buka AppImage/.deb di Linux.

Buat admin

First-run: buat akun admin aplikasi (password minimal 8 karakter).

Connect router

Masukkan IP, user, password MikroTik. Pastikan API aktif di port 8728.

Persyaratan

Minimal agar connect dan generate voucher berjalan lancar.

  • Windows 10/11 atau Linux desktop modern (x64)
  • MikroTik RouterOS dengan layanan API aktif (`/ip service` api)
  • Router & PC di jaringan yang saling mencapai (lokal)
  • Hak akses user MikroTik cukup untuk hotspot user/profile
