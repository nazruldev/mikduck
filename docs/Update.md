# Update & channel

## Sumber update

Auto-update / cek versi memakai **GitHub Releases** publik:

https://github.com/nazruldev/mikduck/releases

## Channel di Settings

**Settings → Preference → Channel update**

| Channel | Isi |
|---------|-----|
| **Stable** | Produksi (default) — hanya rilis non-prerelease |
| **Beta** | Uji fitur hampir siap (`*-beta`) atau stable lebih baru |
| **RC** | Release candidate |
| **Alpha** | Uji paling awal |

User **stable** tidak menerima build beta/alpha/rc.

## Cara update manual

1. Buka [Releases Latest](https://github.com/nazruldev/mikduck/releases/latest) (atau prerelease yang sesuai channel)
2. Unduh Setup / Portable / AppImage / `.deb`
3. Install / jalankan di atas versi lama

## Catatan versi

Hanya build **terbaru per channel** yang relevan untuk client; website download juga menekankan latest-only.
